# 双平台独立会话，共享获准记忆与陪伴业务

用户已确认：ClawChat和QQ连接同一伙伴实例，各来源会话分别保存和恢复；主人明确关联账号后，共用获准的长期记忆。人格、心情及各陪伴能力沿用一个权威实现，日记与主动活动不因增加平台再运行一套。平台认证、消息格式、专属动作及回执由各Adapter处理。安装包是否分开不决定业务或数据是否分成两套。

选择依据是已确认的云端陪伴目标、Aurabot按聊天建立会话的结构，以及优先复用原业务的要求。完整会话合并没有已确认的产品需求，却会增加来源、上下文及投递协调工作，因此不作为当前方向。跨端完整历史、即时话题、图片和工具上下文不自动共享；以后如需这些体验，先明确新目标并经用户确认修订本决策，不能自行改变默认会话结构。

共享记忆不等于所有内容均可被日记、主动分享或公开动态读取。各模块按已确认的来源、身份和受众取材，私人日记和平台发布分别处理。后台同一活动只执行一次，投递按目标通道保存独立回执，普通回复返回原会话；不因接入QQ默认双发或启用新的后台行为。

本决策固定会话和共享规则，实际代码、兼容迁移与真实账号验收分别按状态记录；共同归属不能代替真实QQ关联及收发验收。保留既有数据及可见范围，不合并两端完整会话或复制一套业务。产品范围见[双平台关系](../PRODUCT.md#clawchat-与-qq-的关系)，当前事实见[状态](../STATUS.md)。
