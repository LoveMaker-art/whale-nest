# QQ 通道接入

在已配对的 ClawChat 主人私聊说「连接 QQ」。鲸栖在宿主的兼容网关取得机器人 QQ 登录二维码，等待手机确认，校验实际账号及聊天通道。登录和主人关联是两个步骤。[产品设计](../PRODUCT.md#云端用户的管理入口)

## 已确认的扫码登录体验

1. 用机器人 QQ 扫码，并按 QQ 手机提示完成确认。
2. 原聊天会自动提示后台核验结果。机器人登录后，在个人 QQ 里按提示发送验证文字，并回原 ClawChat 私聊确认关联。
3. 恢复同一个机器人时沿用已核验的主人关联。确认 OneBot 聊天通道可用后通知原私聊。

适配器区分有效二维码、手机验证待完成、二维码过期与连接失败。仍有效的登录流程可继续使用。关联码和确认指令由程序原样显示，说明优先由模型依据实际状态组织。[回复设计](../technical/reply-delivery.md)

## 接入范围与真实验收条件

OneBot 网关由宿主提供。鲸栖负责原聊天接入、扫码状态对接、主人关联和授权范围。已获准共享的数据归同一伙伴实例，两个渠道各自保留会话、附件和发送回执。网关断开时原 ClawChat 会话仍可使用。[双端规则](../PRODUCT.md#clawchat-与-qq-的关系)

通过实际手机扫码测试登录及重新连接，核对双端私聊、共享记忆召回、引用归属、解绑和重绑。验证真实消息、附件和客户端呈现依各自样本记录。当前状态见[验收矩阵](../STATUS.md#功能交付)。

## QQ 内存保护与常驻验收

在目标 2 GiB 宿主核对 DSH 和网关共存。资源压力下可延后的后台任务按既有门禁等待，聊天继续走原会话。运维核对实际容器限制、内存事件及服务状态，见[网关维护](../DEVELOPMENT.md#qq测试网关运维)。
