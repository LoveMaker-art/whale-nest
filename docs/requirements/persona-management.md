# 基础能力需求：人格管理

已确认功能需求；对应[技术设计](../technical/persona-management.md)。实际部署、启用与验收以[STATUS](../STATUS.md)为准。

## 1 基础要求

| 编号 | 需求 |
| --- | --- |
| P-01 | 接入Aurabot已有的人格管理，复用原卡片逻辑。 |
| P-02 | 同一实例跨ClawChat、QQ共用人格库和当前选择，完整会话仍分别保存。 |
| P-03 | 当前角色的正式自称为「鲸鱼娘」，昵称「大肥鱼」，表达见[人格卡](../whale-girl-persona.md)。当前构建包的初始预置仍使用固定的原始大肥鱼参考卡。 |
| P-04 | 原始来源和许可保留；人格正文、真实平台和工具说明分开提供。 |
| P-05 | 主人在现有聊天中管理人格，由工具实际执行，不新建独立页面。 |
| P-06 | 先确定需求，再开发和回归；本需求文档不代表已经实现或立即部署。 |

## 2 首轮操作

| 编号 | 用户可见行为 |
| --- | --- |
| P-07 | 列出人格，显示当前选择。 |
| P-08 | 查看指定人格的名称、标签和正文。 |
| P-09 | 新建并保存人格；保存不自动启用。 |
| P-10 | 编辑运行人格卡，返回实际保存结果。 |
| P-11 | 切换后下一轮生效，当轮不混用正文；重启保留选择。 |
| P-12 | 删除非当前卡；正在使用的人格不能删除，沿用原版规则。 |
| P-13 | 保留原始大肥鱼原文，可用该原文重新创建/选用人格；不要求新增一键恢复系统。 |

切换只改变角色设定，不自动清空、复制或分区记忆、心情和经历。管理权来自可信主人身份；其他参与者和后台任务不能修改人格。

## 3 默认人格与数据

当前构建包预置的正文来自[原始参考卡](../../vendor/persona-reference/persona.md)，摘要见[来源锁](../../upstream.lock.json)。测试机使用修订后的[鲸鱼娘人格卡](../whale-girl-persona.md)。两份卡的来源和表达出处见[人格资料](../persona-sources.md)，已启用版本见[当前状态](../STATUS.md)。

首次初始化导入并选中随包预置。重启和升级保留用户已有选择和卡片。编辑作用于运行卡，原始参考副本用于溯源和恢复。保存失败时反馈实际结果。

## 4 基础验收

| 编号 | 通过条件 |
| --- | --- |
| A-01 | 默认原文及来源正确，重复初始化不覆盖选择。 |
| A-02、A-05、A-08 | 主人通过对话完成CRUD，非主人不能管理，当前卡不能删除。 |
| A-03、A-04 | 下一轮实际请求使用新卡，共用一份选择；真实QQ收发后续验证。 |
| A-06、A-07 | 普通重启保留选择，原Session、记忆、心情和经历不被清空。 |
| A-11 | 原ClawChat对话和媒体功能正常，无新增管理页面。 |

真实QQ收发在M4按同一需求验证；复杂并发/故障恢复和AI润色不作为基础管理的前置。

## 5 后续保留

P-14自定义初次默认、P-15 AI润色、P-16导入导出/复制/用户版本回退暂不做。高级保护、版本冲突和专门恢复流程不阻断基础接线；需要时按真实需求增量增加。产品仍遵循[既定双平台方向](../adr/0002-cross-channel-conversations.md)和[开发流程](../../AGENTS.md)。
