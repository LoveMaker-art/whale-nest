# 鲸栖 1.0.0-beta.2

面向已预装鲸栖的 Linux x64 ClawChat 云实例。配对后可以与「鲸鱼娘」聊天、收发语音、使用实时通话，按需关联 QQ。

- 新实例默认使用鲸鱼娘音色，日常语音和鲸栖通话共用。已有实例优先读取保存的音色。
- 鲸栖自有代码采用 MIT 许可，安装包随附许可证和第三方声明。
- 已配置鲸栖 GitHub 发行源的 Beta 实例可以在主人私聊说「检查更新」，并输入提示中的完整确认指令。

安装资产包含 Linux x64 `.connect-plugin` 和 `distribution.json`。用量和宿主兼容要求见[开发与安装](../DEVELOPMENT.md)。
