# 鲸栖 1.0.0

面向已预装鲸栖的Linux x64 ClawChat云实例。本版将近期已验收的解耦、更新器、首启与陪伴功能整理为正式源码及运行包；发布完成与当前实例事实以[STATUS](../STATUS.md)和GitHub发行资产为准。

## 本次变化

- 平台接入使用官方公开Runtime、工具和管理接口；移除自有Core补丁、私库读取与私有会话钩子。官方连接器由用户独立更新。
- 实时通话使用鲸栖自己的独立DSH线程，保留识别、回复、播放、打断及授权长期记忆；不自动读取或回写原私聊近期历史。
- 消息、图片、语音和文件经官方工具投递。业务产物、稳定请求和真实回执由鲸栖维护，未知结果不盲目重发。
- 更新器从GitHub Releases查版、主动提醒，主人确认后只更新鲸栖。连接器与DSH版本不作为更新门槛；官方连接器只读查版，由用户决定是否更新。
- 补齐公开回退版本信息的读取，支持核对原版本后恢复；安装、恢复及重启接续保留用户新增数据。
- 离线安装在停机前核验并保存旧包，失败时通过官方离线入口恢复；启动验收等待管理接口就绪，并记录原始失败原因。
- 首启按身份、基础聊天、头像及官方问候、Liveware、QQ和后台功能依次准备；修复镜像账号判断及QQ停止时的残留处理。
- 保留聊天选择音色、歌曲创作与作品页、预置表情、能力总览、人格、记忆、日记和双端功能。更新托管AGENTS区块并保留区块外的用户说明和个人配置。
- 整理本地开发与测试入口，默认源码回归不构建发行包，QQ原生场景按核心、媒体和活动分类。

## 安装与更新

发行资产为Linux x64 `.connect-plugin`、`distribution.json`及`SHA256SUMS`。更新已有预装实例时保留当前账号绑定、模型接线、用户设置、聊天、记忆和作品；切换期间可能短暂重连。

本包只更新鲸栖和自身受控启动文件，不是整机镜像、DSH或官方连接器安装包。仍需宿主提供实际可用的公开平台接口、实例授权和已配置模型。[安装说明](../DEVELOPMENT.md#现有实例的直接更新)

## 验收边界

发行准备基线通过本地520项源码回归，版本相关本地及Linux各74项通过。随后修正离线安装恢复：相关本地9项通过、4项Linux专用场景跳过，Linux12项通过、1项本机Bun场景跳过；实际发行包通过独立目录及真实DSH加载回归，并通过隔离的正常安装、管理接口延迟、回执丢失及目标异常四条安装路径。集合有重叠，不累加。

最终包已在源机37527实际安装为1.0.0／代际109，498个文件与批准包逐一一致，40项实机检查通过。真实模型调用日记及更新工具，回复经原ClawChat私聊获得平台确认；自测后恢复唯一SDK、鉴权语音端点及两Liveware。本轮保留用户数据，没有重置实例或更新官方0.2.26连接器。

初次候选包切换后的验收失败，其离线恢复误用在线命令，现已修正并通过最终包安装；原始错误当时被恢复错误覆盖，记录中保留该边界。最终验收首次语音端点探测短暂失败，随后有界等待通过，保留初次报告，不把单次健康探测当作完整听感验收。

手机麦克风听感、完整客户端交互、QQ真实账号收发和付费新歌不在本次重复验收范围。通话近期历史与原私聊分离是当前明确的功能取舍。用户体验尚待核对。
