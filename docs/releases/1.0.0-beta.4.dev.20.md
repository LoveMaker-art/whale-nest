# 鲸栖 1.0.0-beta.4.dev.20

面向已预装鲸栖的 Linux x64 ClawChat 云实例。本版对应测试机已启用并验收的 dev.20 运行代码。

- 更新器支持一次确认完整升级路线，按固定版本和 SHA-256 获取中间步骤，由新安装目录的执行器接续原任务，保留重启恢复、去重和回退保护。
- 根据目标发行要求协调官方连接器更新，确认实际运行与原绑定后再更新鲸栖。DSH 版本不作为鲸栖自行设置的更新限制。
- Runtime 和 DSH Bridge 收敛至鲸栖插件；应用中继使用官方 Exposure。保留当前官方接口尚不能等价替代的媒体、权限、通话共享原私聊和正文送达确认扩展。
- 歌曲 Liveware 完成创作问答、哼唱和手绘旋律、作品管理及后台适配；通话继续使用原主人私聊，保留已验收的连接和流式音频策略。
- 沿用鲸鱼娘默认头像、首次开通的通话和歌曲入口，以及原人格、记忆、QQ 和创作功能。

## 安装与更新范围

发行资产包含 Linux x64 `.connect-plugin`、`distribution.json` 和 `SHA256SUMS`。运行包与测试机 dev.20 包逐字一致，元数据声明 `updateProtocol: 1` 及官方集成包最低版本 `0.2.23`。

本包用于已完成配套接线的预装实例，不包含定制 Core 二进制和整机安装环境。测试组合为官方集成包 `0.2.23`、官方程序/Skills `0.1.0-beta.9` 及自有 Core 构建 `0.1.0-beta.9-whalenest.0.2.23.2`。安装 Runtime 包不会自动为纯官方实例补装这些扩展，也不替代较早定制底座的配套迁移。具体操作见[开发与安装](../DEVELOPMENT.md#现有实例的直接更新)。

当前仍有四类必要 Core 接口、最小只读状态依赖和配套启动；本版未宣称完全解耦。未来平台补齐通用接口后，迁移代码可通过本版升级路径机制到达并执行，具体迁移仍须单独适配和验收。[接口与解耦边界](../technical/clawchat-connector-platform-handoff.md)

## 验收

dev.20 本地96项、Linux95项相关回归通过，实际Core包安装和入口激活通过，测试机420份sources摘要与候选一致。真实模型在原通话桥调用更新状态工具并取得原私聊回执。发布前重新核对聊天就绪、当前连接器33份资产、唯一SDK/Core/官方中继、通话鉴权、歌曲页面及三个App路由均通过。

手机麦克风听感、完整客户端交互和付费新歌生成未在本轮重新测试。历史功能与覆盖范围见[当前状态](../STATUS.md)，升级引导实现见[更新任务](../tasks/plugin-updates.md#发布前提前实现升级路径与新版执行者接续)。
