# 日记与经历档案开发设计

依据[已确认需求](../requirements/diary.md)描述实现与数据归属；实际部署、启用与验收以[STATUS](../STATUS.md)为准。

## 1 复用选择

开发前原[diary模块](../../vendor/aurabot/src/modules/diary/index.js)装配createQzone与图文生成器；[createQzone.writeDiary](../../vendor/aurabot/src/features/qzone.js)默认面向QQ空间，普通分支读QQ聊天。符合本期取材规则的是[createDiaryMedia.compose](../../vendor/aurabot/src/modules/diary/media.js)，但它默认取近48小时材料、允许无经历只写心情，还带公开配图流程，不能直接打开模块开关当作私人日记。

沿用原compose的提示组织、生成和正文解析，只补日期、获准活动材料、执行入口及必要配图选项；本期无素材直接跳过，不走聊天分支或仅心情兜底。当前[src/diary.mjs](../../src/diary.mjs)保留私人保存、查询、版本、删除与去重，停止承担第二套正文拼写。两者是生成与存储的分工。

## 2 改动位置与执行

| 位置 | 必要改动 |
| --- | --- |
| 原diary/media及[sources](../../vendor/aurabot/src/modules/diary/sources.js) | 允许传入指定日期的实际活动材料及共享模型执行入口；默认原调用保持兼容。私人生成不要求QQ登录、QQ空间受众或空间发布开启。 |
| 原diary模块与[兼容构建器](../../scripts/build-aurabot-host.mjs) | 暴露同一compose能力供两端使用，接原活动取材分支；保留原QQ空间工具，不另外启动自动空间日记tick。 |
| [companion-service.mjs](../../src/companion-service.mjs) | companion_diary的手动整理与自动任务调用同一生成入口；移除旧自动提示里另让模型自由写感想的重复生成。读、删、列表仍用现有工具。 |
| [diary.mjs](../../src/diary.mjs) | 接收原生成正文及准确来源，保留事实与感想的区分；迁移为主人共同scope，旧日期、版本、请求去重和删除状态保留。 |
| [diary-publisher.mjs](../../src/diary-publisher.mjs)与原Qzone.post | 私人保存后才按明确要求走对应发布出口。QQ空间沿原发布方法，ClawChat动态沿现有发布适配；按平台、作品版本及受众分别保留回执。 |

执行：已有整理工具/唯一21:00任务 → 按北京时间日期读取已完成活动 → 无素材、已删除或已有自动日记则跳过 → 原生成器一次生成 → 私人档案保存 → 按需查询、通知或明确发布。自动模型调用逐次占共同预算，通知另查联系名额；手动查询不等待主动冷却。

取材来自同一活动档案，保留实际资料覆盖范围；不把近48小时全部材料混作当天，不读取私聊、私聊摘要或私人记忆。人格与心情只影响表达。首轮不新增配图生成，不自动读取本地任意目录；已批准的活动配图能力保留，是否启用按现有设置，不为凑图额外调用模型。

## 3 一份档案与一条生成链

依照[共用接线](proactive-delivery.md)迁移旧route scope；活动来源ID和历史发布回执不变。同一日期并发整理复用已有任务/请求记录及进程内互斥；自动最多一篇，主人明确重新整理才新增版本。删除记录仍阻止自动重建，重启不丢失。

两端主人查询同一份档案，回复查询会话。完成通知继承全局首选，默认私人保存不等于公开发布。当前发布预览只采用已核准的公开活动事实；不把私人正文直接当作获准公开稿。公开发布仍需核对平台、正文和受众，首选平台不代替发布授权。

原聊天取材分支源码保留，当前不作为直发或自动入口；原QQ空间post/remove继续通过独立确认使用。只运行一个本期日记生成入口；旧自写生成提示与原自动空间生成不能并行写同一天。已有历史不批量重新生成。

## 4 回归与交付

在现有diary、diary-publisher、companion-service-native及native-qq回归中验证原compose真实被调用：当天活动取材、只有私聊不生成、日期边界、额度为0不后台调用、私人保存不发布、两端读同一版本、明确发布的独立回执。验证重复请求、并发、重启、删除、旧档案迁移及回退保留新数据。

实机保留当前自动开关，先由Agent在ClawChat手动整理限定真实素材并查询、核对持久记录；QQ先真实SDK与模拟网关，账号授权后再做真实联调。生成成功、归档成功与通知成功分别记录，不能用其中一个替代其余结果。


## 5 已落地接缝

[构建器](../../scripts/build-aurabot-diary.mjs)校验固定来源，生成原media及模块兼容文件；[diary-adapter](../../src/diary-adapter.mjs)接原Hub、共同预算和投递，原分钟tick不再独立运行。正文来自原compose，现有档案只保存正文/来源/版本及请求状态；原ClawChat发布ID保留，QQ另记平台回执。首轮私人生成仅文字，不开启新增配图或聊天取材。
