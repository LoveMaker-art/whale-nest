# 平台唱歌需求

已确认功能需求；对应[技术设计](../technical/singing.md)。实际部署、启用与验收以[STATUS](../STATUS.md)为准。

## 1 已确认的用户体验

| 场景 | 要求 |
| --- | --- |
| 请求唱歌 | 主人明确说“写一首关于……的歌”“把这段歌词唱出来”等，Agent 根据请求准备歌词及风格，调用平台唱歌服务。缺少必要主题时才澄清。 |
| 接收歌曲 | 生成较慢时说明正在制作；完成后保存歌曲并发回发起请求的会话。优先发送可播放音频，格式或大小受限时明确作为可下载音频文件发送。 |
| 在 ClawChat 回听和看谱 | 私聊音频确认后附上该作品的 Liveware 卡片。主人也可单独请求已有作品的入口。作品页支持播放、暂停、拖动进度，并可浏览原歌词、五线谱和自己的其他作品。页面仅供关联主人访问，乐谱暂不可用时仍能听完整首歌。 |
| 演唱声音 | 使用平台现有声音条件：默认随歌曲风格生成，明确选择时可使用其已提供的预设。不要求与当前 TTS 音色一致，不新增自定义音色上传或管理。 |
| 作品与状态 | 能查询已生成歌曲及其状态，并重新发送已有作品；重发不重新生成。QQ、ClawChat 使用同一份获准共同作品。 |
| 触发范围 | 首轮仅处理主人明确请求，一次请求生成一首；普通聊天、心情和后台活动不自行生成歌曲。 |

本项不以原曲录音、原编曲、指定歌手或固定“大肥鱼音色”的还原为验收目标。用户只给熟悉歌名时，不承诺自动取得准确原曲并完成翻唱；需要说明当前能按平台服务生成歌曲。平台的乐谱重唱、哼唱提谱和谱面编辑保留能力记录，不作为首轮文字请求唱歌的前置条件。

## 2 平台及共用规则

生成使用 ClawChat 所属平台提供的 SongSmith/MusicHub 服务，复用本实例已有配对认证。不安装本地唱歌、分离或 RVC 模型，不改接外部推理服务，也不要求用户维护个人电脑。

同一实例只有一套唱歌任务和作品状态，两端共用；手动结果回原会话，不随全局主动消息首选变化。原 RVC 翻唱路径保持关闭；本次产品目标调整不删除其上游源码或把它作为第二套运行实现。

唱歌与当前 TTS 说话分别调用平台服务；不改变已经可用的默认说话音色。歌曲不会自动加入表情库、发动态或群发。

## 3 用量与真实验收

真实生成验收须单独确认平台条件、费用及有界用量，图像或TTS授权不自动延伸为歌曲生成。一次授权只覆盖其明确范围；未知结果保留原任务，不盲目重提。

前台唱歌按平台实际服务规则计费，不占现有每天 5 次后台模型请求额度。没有取得单价或余额时如实说明，不承诺免费、固定价格或无限生成。超时、断线等结果未知时保留记录；查询已有任务、下载或重发已有作品不另起生成。

首轮验收：一条明确请求能完成平台真实生成、持久保存及 ClawChat 实际音频/文件投递；再次查询或重发不生成第二首；失败、未知状态及重启恢复可区分。两端应调用同一执行入口，真实 QQ 客户端验收仍待账号接入，不以模拟结果代替。

## 4 本轮暂缓

生视频暂不接入；保留既有视频附件发送能力及 WAN3 核查资料，不启用视频生成、不提交视频任务。唱歌的固定角色音色、原曲 RVC 翻唱也不纳入当前开发目标。
