## 当前更新边界：官方连接器只检查，不代更新

11月28日用户在完成公开接口收敛后明确调整：鲸栖只帮助检查官方连接器的实际运行版本和官方最新版本，是否更新由用户决定。自身更新不再自动升级或回退官方连接器，不以历史连接器最低版本或DSH版本作为门槛；保留实际接口、主人归属、会话空闲、实例格式及包来源完整性检查。旧连接器变更任务如仍在途，只保留证据并提示用户核实，不重新提交变更。

本项覆盖此前“先更新连接器再更新鲸栖”的协调要求。源码、回归及指定源机验收进度以STATUS为准，安装包与公开发行仍分别等待授权。[当前流程](tasks/plugin-updates.md#当前要求官方连接器只检查不代更新)

## 已确认前提：先核实平台能力

语音、图片、唱歌等每项扩展先核对：

1. 实际服务与支持能力，识别、生成和消息发送分别判断。
2. 接口、型号、鉴权、格式、文件限制、任务完成及错误处理。
3. 权限、当前额度、计费、并发和云端资源；目录列出型号不代表当前请求可用。
4. 与用户确认体验、范围和有界真实用量，再接线并分别验证真实处理、消息送达和客户端效果。

仅使用平台后端；未确认项保留依赖，不静默改用外部订阅或本地推理。模拟与真实结果分开记录，平台失败不继续盲目付费重试。新增能力及后端变更沿用此规则，已确认的陪伴需求保持。
