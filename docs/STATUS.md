## 实例设置

Beta 以平台提供的 2 GiB 实例为目标。预置实例按[产品基线](PRODUCT.md)配置模型、语音、生成服务和伙伴默认值。现有实例升级沿用已有数据与设置。随包原始人格和预置实例角色见[人格管理](requirements/persona-management.md)。真实账号、会话与素材归实例存储。

测试机恢复为空白使用状态，运行卡为「鲸鱼娘」，北京时间 21:00 定时整理已启用。QQ 和 B 站账号待登录。ClawChat 配对和 Liveware 接入保留，平台聊天记录按平台保存，本机以空白会话开始。

测试机日常语音和「鲸栖通话」共用新默认音色 `qwen-audio-3.0-tts-flash-fy1ae4cdd1-95f01c83d3984a62bffbfcaae018a8cf`。已用现网语音后端合成 3.09 秒普通话，通话服务配置校验和重启后的健康检查通过。
