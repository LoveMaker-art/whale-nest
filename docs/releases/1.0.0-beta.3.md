# 鲸栖 1.0.0-beta.3

面向已预装鲸栖的 Linux x64 ClawChat 云实例。

- 新实例首次绑定时，空白头像使用微笑版鲸鱼娘。已有头像按原资料保留。
- 首次开通默认启用「鲸栖通话」和「鲸栖歌曲」，配对后登记为原 ClawChat 会话的私有入口。
- 通话页等资料确认后显示头像，减少打开页面时的头像切换。

安装资产包含 Linux x64 `.connect-plugin` 和 `distribution.json`。已配置鲸栖更新源的实例可以在主人私聊说「检查更新」。宿主要求和开通方式见开发说明。[开发与安装](../DEVELOPMENT.md) · [状态与验收](../STATUS.md)
