# SongSmith 功能适配核对

依据固定的 SongSmith 1.0.6 发布物，对照鲸栖的[歌曲需求](../requirements/singing.md)和[接线设计](../technical/singing.md)。原始包、源码比对、实机对话、回归及部署证据统一保存在 `.whale-nest/verification/song-melody-diagnosis-20261124/`。运行事实以[当前状态](../STATUS.md)为准。

## 核对方法和交付

原版页面、服务端、生成脚本、songwriting 技能及 humming/score-editing 参考分别核对。每项沿页面或聊天输入追踪到模型实际收到的指引、可信身份、持久档案、平台参数、结果回执和页面显示。对已确认缺口先构造失败回归，再补齐。本地通过后使用既有更新入口部署测试机，保留原账号、会话、旋律、歌曲及未知回执。新版本发行另行申请。

本表中的“已有”表示已找到实现，不能单独作为本次验收通过的依据。完成时记录对应测试及真实执行边界。
