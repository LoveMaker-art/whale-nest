# 鲸栖 1.0.0-beta.1

首个测试版面向配对开通的 ClawChat 云实例。测试用户可以和「鲸鱼娘」聊天，关联 QQ，在两端使用同一个伙伴的获准记忆、心情、日记和作品。完整会话和附件按通道保存。

- 支持文字、图片、语音和表情。在已经配置对应平台服务的实例上，可识别语音和图片、合成语音、生成图片和歌曲。
- 支持 B 站公开搜索和资料读取、私人日记、主动联系和首选通知平台。自动活动按各自设置启用。
- ClawChat 提供「鲸栖通话」和「鲸栖歌曲」。通话结束后可以回到原私聊继续，作品页可播放已保存歌曲并查看已取得的歌词和乐谱。

测试版通过 Linux x64 `.connect-plugin` 和 `distribution.json` 交付。QQ 扫码使用宿主配置的兼容网关。新开实例的完整配对、最新版客户端体验、B 站登录后的操作、QQ 非空收藏导入和公开发行源的私聊更新见[验收状态](../STATUS.md)。
