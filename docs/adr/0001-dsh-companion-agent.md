# 基于 DSH 的陪伴型 Agent

鲸栖定位为基于 DSH 的云端陪伴型 Agent，交付持续运行的伙伴及其人格、记忆、状态和行动能力，商业交付围绕云实例与模型用量展开。ClawChat 承载分发与管理，ClawChat 与 QQ 分别收发消息；插件承担能力扩展、适配与分发，是产品开发中的一环。

技术实现采用 Aurabot 的陪伴流程和模块体系作为来源，改造宿主、身份、投递及管理接线，用户管理以现有聊天为入口。这一选择复用已有业务联动，同时承担解开 QQ 与 DSH Web 耦合的迁移成本；具体来源与署名见 [上游与许可](../UPSTREAM.md)。

## 后续约束

用户进一步明确：直接采用 Aurabot 整合插件，其内置记忆、心情和 B 站模块替换旧的独立插件，不将旧后端作为默认装配选项。每个伙伴实例只保留一套权威记忆、心情和主动联系状态。现有 DSH、ClawChat 底座、原生调度、投递回执和实例权限继续复用；旧插件代码、许可和私有数据保留作追溯与恢复依据。

ClawChat 和 QQ 共享陪伴能力，平台收发分别由 Adapter 实现。ClawChat 可按另行确认的范围扩展实时通话，使用同一 Agent 的人格和有权限的长期记忆；它不预设另装一套陪伴插件，也不要求 QQ 同步具备通话能力。通话复用平台 Liveware，部署与验收见[实时通话任务](../tasks/realtime-call.md)。

本决策记录迁移前的选型依据；迁移和后续实际部署按[阶段计划](../MIGRATION.md)及[STATUS](../STATUS.md)判断。此决策不更换已选人格、不重置当前实例的完整权限与免审批配置，也不自动启用 QQ 登录或外部账号互动。
