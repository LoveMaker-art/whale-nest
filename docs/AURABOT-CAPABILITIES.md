# Aurabot固定版本功能清单

核对日期：2026-11-16。依据本仓库固定的Aurabot **1.2.1 / a138d14e3215f052dfa7d6a9dd16c0e409d9752d**，原文件来源及校验见[UPSTREAM](UPSTREAM.md)。本文描述上游提供什么，不代表这些功能已在鲸栖启用或已适配ClawChat；当前实际采用的实现见[实现归属清单](IMPLEMENTATION-INVENTORY.md)。

Aurabot是DSH上的整合陪伴插件，包含宿主接线、16个内置能力模块和社区模块扩展入口。DSH仍负责模型与Agent执行；QQ实际登录及动作依赖OneBot网关。模块存在、模块启用、外部后端可用、平台真实发送成功分别判断。原总开关默认关闭、dryRun开启，不能说安装后全部功能即生效。

## 16个内置能力模块

数量及启动顺序来自[BUILTINS](../vendor/aurabot/src/modules/index.js)。

| 模块 | 用户可感知的原功能 | 主要条件与范围 |
| --- | --- | --- |
| [长期记忆 memory](../vendor/aurabot/src/modules/memory/index.js) | 记住事实、偏好和约定；相关回忆、人物档案、关系和群印象；按配置提炼整理、短期状态、压缩和可选向量检索；管理界面可查看、纠正及删除 | 记忆按身份、来源及可见范围读取。各自动功能分别配置；跨平台需要接入同一身份与存储，不能靠相同昵称自动共享 |
| [心情 mood](../vendor/aurabot/src/modules/mood/index.js) | 互动推动心情变化，随时间回归基线；影响语气、表情和语音概率、回复速度及群参与倾向 | 可选关键词或额外模型判断，后者增加模型调用；表达联动还依赖相关模块与聊天中枢 |
| [表情包 stickers](../vendor/aurabot/src/modules/stickers/index.js) | 收录聊天图片/表情、起名和标签、查询和整理；按情绪发送；导入QQ收藏，画作也能收为表情 | 通用图库与QQ收藏动作不同，后者依赖实际网关；自动收录和管理权限可配置 |
| [语音 voice](../vendor/aurabot/src/modules/voice/index.js) | 把回复合成为语音条；多种TTS接线、试听、自检；可联动翻唱音色做RVC变声 | 包含edge-tts、Windows语音、CosyVoice、GPT-SoVITS和本地接口等接线，需实际后端；入站识别由聊天中枢和宿主STT/本地ASR共同承担。不是实时通话 |
| [基础QQ工具 qq-tools](../vendor/aurabot/src/modules/qq-tools/index.js) | 翻历史消息、跨天搜索聊天流水、读取文本文件、发送文件和图片；向获准好友/群发消息，发送支持的卡片 | 受白名单、来源及文件目录限制；不同网关支持的动作有差异 |
| [扩展QQ接口 qq-api](../vendor/aurabot/src/modules/qq-api/index.js) | 搜索并调用获准QQ动作，例如查公告、精华、荣誉、群文件，或撤回、改名片等 | 不是任意接口无条件开放；动作、发言人权限和实际网关支持都要核对 |
| [生图 imagegen](../vendor/aurabot/src/modules/imagegen/index.js) | 文生图，参考当前/引用图片或旧画作改画；选择构图，保存画作并发送，记录创作经历 | 依赖兼容生成后端及参考图支持，不是插件自带免费生图模型 |
| [空间日记 diary](../vendor/aurabot/src/modules/diary/index.js) | 定时或按需写QQ空间说说；普通日记根据当天聊天流水生成，图文分支使用公开经历及候选图片；预览、选图、署名、发布历史、删除与受众控制；成功发布可写回记忆 | 普通和图文分支取材不同。原公开浏览图片archive不是当前私人按日修订档案；不自动读取所有DSH原生会话 |
| [空间互动 qzone-social](../vendor/aurabot/src/modules/qzone-social/index.js) | 查看自己的说说评论并回复；逛好友动态，按设置点赞、评论 | 与写日记是独立模块；需要QQ空间相关动作及账号权限，不会自动成为ClawChat动态互动 |
| [主动搭话 speakup](../vendor/aurabot/src/modules/speakup/index.js) | 主人长时间未互动时主动私聊，从真实素材、上次话题、记忆或时间选择由头；作息、次数、随机间隔、静默、可选追问和白名单联系 | 原默认出口为QQ私聊；需要共享宿主及通道适配。purpose启用时原tick让路，不能两套同时联系同一人 |
| [目的引擎 purpose](../vendor/aurabot/src/modules/purpose/index.js) | 从人格、记忆和近期流水形成观察及目标候选，选择是否主动联系；记录节奏和结果，可选择QQ或桌宠出口 | 实验功能、默认关闭；与基础主动搭话互斥，桌宠出口依赖社区pet模块，不等于任意独立业务双发 |
| [B站 bili](../vendor/aurabot/src/modules/bili/index.js) | 读取标题、简介、字幕、热评；按兴趣浏览、评论、回复评论、点赞、向主人分享；可选弹幕、抽帧理解与发截图，按权限修改自己的B站头像/签名 | 登录、视频资料可得性、视觉模型、ffmpeg及网关分别影响可用性。原模块不等于本项目后来补的二维码登录、私信、动态、三连及统一消息监控工具全集 |
| [翻唱 song](../vendor/aurabot/src/modules/song/index.js) | 按歌曲制作音色翻唱，可变调、清唱，完成后发送；与语音共用可用音色 | 依赖歌曲来源、分离/转换工具、模型及运行资源；不是当前2GiB云机默认本地运行能力 |
| [资料 profile](../vendor/aurabot/src/modules/profile/index.js) | 查看QQ昵称、签名及头像，读取头像画面或发送头像；按权限修改自己的昵称、签名、头像 | QQ专属资料字段与动作；换成ClawChat需要使用其实际资料能力 |
| [申请与白名单 contacts](../vendor/aurabot/src/modules/contacts/index.js) | 处理收到的好友申请、加群申请或邀请，管理获准私聊和群 | 处理好友申请不等于可主动加任意人为好友；权限和网关支持分别判断 |
| [生视频 video](../vendor/aurabot/src/modules/video/index.js) | 调用本地配置的生成接口/脚本，完成后把视频发到聊天 | 依赖生成后端和运行环境；接线存在不表示附送视频模型或算力 |

## 面向多平台改造的三类划分

本节按用户提出的三类描述固定源码，不是后续开发清单。分类依据是**原模块整体的主要职责**，同时标明可提取的共同业务与平台专属子功能；不能用工具名含qq或某条发送调用，推断整个模块只能在QQ使用。实际采用范围以现行产品、规格及STATUS为准；各会话使用同一模块不等于共享全部原文或不受权限限制。

### 第一类：伙伴基础能力

| 能力及源码归属 | 原版职责 | 多平台改造边界 |
| --- | --- | --- |
| 人格：host.js与persona/personas.js，不属于16个BUILTINS | 人格卡、切换、编辑及预设接线 | 保留同一角色及当前已选原文；各会话另提供真实平台、身份及工具说明；不能将人格文本视作实际已具备的平台能力 |
| memory | 长期记忆、人物与关系、检索、整理及可选短期状态 | 原实现依赖QQ人物与私聊/群聊键，需要明确身份关联和来源过滤；共用获准长期记忆，不全量灌入跨平台聊天，也不因适配自动开启原全部后台能力 |
| mood | 心情变化、时间衰减和表达倾向 | 同一伙伴保留一个状态；适配输入事件及会话上下文，过滤私聊原因；表情/语音/速度等效果还需具体执行接线 |

模块内核、宿主执行、会话管理、身份权限、配置和持久化属于技术支撑，不能再算成额外内置能力模块。DSH原生模型/工具执行也不能计为Aurabot自己实现的能力。

### 第二类：主体可跨平台复用的活动与表达模块

这些模块的业务对象不是QQ账号本身，但现有实现仍含QQ入口、身份或投递依赖，不能描述为零改动通用。

| 原模块 | 可复用的主体 | 需要针对性适配的部分 |
| --- | --- | --- |
| bili | B站资料读取、浏览、互动、摘要与相关经历 | 工具挂载、主人与B站账号映射、经历记录、自动执行及分享/截图出口；当前已确认的补充功能继续保留 |
| voice | TTS及音色处理，向调用方返回音频 | 实际语音发送、QQ语音自检及后端接线；ASR入口还涉及聊天中枢与宿主STT，不把它虚构成独立原模块 |
| stickers | 图片库、标签、匹配、整理与选择 | 各平台接收及发送；QQ收藏导入/同步是本模块内的平台专属子功能，不能随共同图库操作自动执行 |
| speakup | 联系条件、话题选择和表达提示 | 原QQ主人、最近互动及目标会话映射，改接明确的通知目标与统一预算；一套策略生效 |
| purpose | 观察、目标候选与主动决策 | 人物与素材范围、会话执行及QQ/桌宠载体路由；实验功能仍需单独启用，与speakup互斥 |
| imagegen | 生图/改图请求、作品与创作经历 | 参考图来源、权限、后端与图片发送；先核实平台生成条件，不因完成分类就启用 |
| song | 歌曲来源、分离、变声、混音 | 原已有发送回调，但仍需映射来源会话、经历归属和音频投递；后端与资源单独核验 |
| video | 调用生成后端并处理结果 | 后台任务生命周期、视频/文件出口和失败回执；现有脚本依赖不等于当前云端后端可用 |

### 第三类：以QQ平台对象和操作为主体的模块

QQ特有指这些现有实现直接操作QQ账号、空间、群、申请和消息；不表示其他平台没有相似功能，也不表示任何代码都不能复用。

| 原模块 | 为什么整体归此类 | 可以复用或提取的部分 |
| --- | --- | --- |
| diary：原名空间日记 | 生成后面向QQ空间发布，含QQ受众、tid、历史、删除及记忆回写，不是独立私人日记模块 | 正文生成、公开素材收集、选图、署名可提取为共同能力；QQ发布留在QQ，ClawChat动态单独适配；私人档案是已有新增要求 |
| qzone-social | 读取QQ空间列表/评论楼层，点赞、评论和回复 | 表达提示、部分互动原则及节奏可复用；动态/评论结构、人物、去重及受众分别适配，不能直接替换动作名 |
| profile | 查询和修改QQ昵称、签名及头像 | 一般意图和部分图片处理可复用；ClawChat资料走自己的字段、身份与权限 |
| contacts | 处理QQ好友/群申请、邀请及白名单 | 授权判断和管理意图可参考；各平台申请标识、账号和白名单分别管理，主人身份关联不是QQ好友申请 |
| qq-tools | 以QQ聊天历史、卡片、文件和指定好友/群消息为直接工具对象 | 文件处理和部分通用消息意图可提取，QQ历史/卡片等继续保留专属实现 |
| qq-api | 查询和调用OneBot的QQ动作 | 动作目录及执行保留为QQ专属，ClawChat提供实际存在的对应动作，不建立虚假的一一映射 |

正式内置模块计数为第一类2个、第二类8个、第三类6个，合计16个；人格及宿主技术支撑另计。diary整体归第三类与其生成部分可复用并不矛盾；stickers整体归第二类与QQ收藏子功能专属也不矛盾。这是同一职责标准下的模块归类与内部拆分。

## 由宿主提供的能力

这些不计入上述16个内置模块，源码集中在[host](../vendor/aurabot/src/host.js)、[聊天中枢](../vendor/aurabot/src/chat/hub.js)、[人格](../vendor/aurabot/src/persona/personas.js)及[联动](../vendor/aurabot/src/core/bridge.js)。

- 人格卡切换、编辑和预设接线，结合当前模块提供的上下文及规则。
- OneBot连接、事件与机器人账号核对；私聊/群聊分别建立和恢复DSH会话，按聊天选择模型，合并连发、群触发与插话策略、引用和最终回复投递。
- 图片附件接入、音频识别接线、文件与媒体处理；是否理解图片取决于实际模型能力。
- 主人、其他私聊及群聊的工具与记忆范围，敏感动作执行检查、可选审批转发、试运行及静默控制。
- 复用DSH原生长任务/定时任务工具；提供受控子智能体委派入口，后台授权另有配置，不是另造模型引擎。
- DSH Web管理面板、状态与日志、模块安装/替换、配置与备份恢复、更新检查、可选后台峰谷调度。
- 同进程联动对象、其他DSH会话可选的aurabot工具，以及带认证的外部联动入口。它们不意味着原生桌面所有会话的历史自动进入QQ、记忆或日记。

原版默认面板属于上游交付方式；鲸栖继续遵守[产品设计](PRODUCT.md)的不新建独立管理网页要求，不因复用而重新启动整个旧Web入口。

## 社区扩展与不属于原版的能力

固定版本的[说明](../vendor/aurabot/README.md)与[变更记录](../vendor/aurabot/CHANGELOG.md)表明桌宠、抖音、小黑盒、群管等已移到社区模块库，需要额外安装，不在上述16个BUILTINS中。这里列的是固定版本文档所述范围，不是实时市场全量清单。

DSH原生桌面聊天窗口属于DSH宿主，桌宠是可选社区模块，两者不能混称。安装Aurabot不自动合并原有原生会话和它创建的QQ会话。

原版不自带ClawChat收发、ClawChat动态/好友动作或ClawChat实时通话。鲸栖的ASR/TTS由原voice注入平台客户端，具体依赖、接缝及验收分别见[清单](IMPLEMENTATION-INVENTORY.md)。

## 与当前鲸栖的关系

本项目保留原QQ宿主，在同一模块集合增加ClawChat适配；共同陪伴能力与平台专属动作按职责拆分。原文件随包保留不代表全部模块运行，装配模块也不等同真实账号验收。唯一模块集合见实现清单，部署与剩余边界见STATUS。

双平台设计固定为独立Session、获准长期记忆共用和业务单一实现，见[ADR-0002](adr/0002-cross-channel-conversations.md)。本清单不维护运行版本或当前待办。
